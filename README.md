# LLEGATEAPP

Plataforma de movilidad, logística y marketplace automotriz en Venezuela.

## 🛠️ Stack Tecnológico

- Vite
- React
- TypeScript
- Tailwind CSS
- Lucide React
- Radix UI
- Supabase (pendiente de integración)

## 🚀 Cómo iniciar

```bash
npm install
cp .env.example .env
npm run dev
```

## 🎯 Visión del Proyecto

LLEGATEAPP busca unificar mototaxis, encomiendas, turismo y un mercado de repuestos en una sola app, integrando métodos de pago locales para facilitar la movilidad y la logística en Venezuela.
